# Changelog

## 1.1.0

- Added a named external movement-ownership contract so `RenegadeSoldierCombat`, Behavior Trees, State Trees, and other AI systems can use the same `AAIController` without route movement tug-of-war.
- Added actor-level Blueprint helpers for combat and external movement hand-off, avoiding component `Target` wiring mistakes.
- Combat now uses the same ownership contract through the reserved `Combat` claim and still supports destroyed-target auto-resume.
- Multiple independent external systems can hold movement simultaneously; route travel resumes only after every named claim is released.
- Added optional recovery after an unannounced external `MoveTo` interruption. It is disabled by default in favor of explicit claims.
- Added `RenegadeCharacterVehicleComponent` for tanks, harvesters, APCs, and other vehicles implemented as Character Blueprints rather than Wheeled/Chaos pawns.
- Added Light Tracked, Heavy Tank, Harvester, and Custom handling profiles.
- Added acceleration-based movement, capped body yaw, corner speed reduction, tracked pivot turning, reverse-motion control, and lateral-slip damping.
- Character vehicles automatically follow current NavMesh path direction, including detours generated by any compatible combat or route `MoveTo` request.
- Added replicated vehicle telemetry for track/wheel animation, engine audio, dust, and effects.
- Spline followers now auto-detect Character vehicles and use larger vehicle-friendly look-ahead, acceptance, and route-end distances.
- Existing 1.0.0 infantry Blueprint API and saved enum values remain compatible.

## 1.0.0

- Initial UE 5.8 source release.
- NavMesh-driven look-ahead spline following.
- Combat pause, target-destroyed handling, delayed resume, and route reacquisition.
- Open/closed routes, forward/reverse travel, lane offsets, team filters, and route groups.
- Failure retry/backoff, external movement suspension, replication, debug drawing, and Blueprint events.
