# Renegade-NXT

<img width="1254" height="1254" alt="RenNXT" src="https://github.com/user-attachments/assets/e562dc64-d013-46f3-a6f3-2b089de417c2" />

C&C Renegade NXT is an open-source third-person action game project being developed in Unreal Engine 5.7.

The project explores and modernises infantry combat TPS, vehicles, team bases, resource systems and single player gameplay inspired by Command & Conquer: Renegade and Renegade X.

==================================================

This project is intended for:

Research and development
Educational purposes
Unreal Engine experimentation
Gameplay prototyping
Community learning and collaboration
Preservation and study of classic gameplay concepts

This is a non-commercial fan project and is not intended to compete with, replace or commercially exploit any official Command & Conquer product.

==================================================

Project Status:

This project is currently in early research and development and is not yet considered playable or production-ready.
Features, assets and systems may change significantly during development.

==================================================

Planned Features:

Third-person infantry combat
Single player Skirmish Matches
Driveable vehicles
Team bases and destructible buildings
Infantry and vehicle purchasing
Harvester Tiberium gathering resource systems

==================================================

Development:

Engine: Unreal Engine 5.7
Programming: Blueprints
Platform: Windows
Status: Early research and development
Project Type: Open-source, experimental and non-commercial

==================================================

Requirement:

Renegade NXT currently uses the NVIDIA DLSS 4.5 Unreal Engine plugin by default. The plugin must be installed for the project to run with DLSS enabled.
DLSS can be disabled and the project can be configured to use Temporal Anti-Aliasing (TAA) instead. When using TAA, the NVIDIA DLSS plugin is not required.
